# USTC 培养计划对照工具（v2）

中国科学技术大学本科培养计划对照 / 课程规划器 —— 纯前端、离线可用、无后端、无构建步骤。

> 打开 `index.html` 即用（双击即可，也可拖到任意静态托管）。

## 功能亮点

- **内置全校公开数据**（首次打开自动汇入，无需联网/登录）：
  - 全部开课 3574 门（含上课时间、教师、容量、开课季）
  - 全部培养方案 1201 份目录 / 1188 份完整模块树（院系→专业→年级→类型）
  - 官方课程替代规则 1165 条
- **数据导入**：粘贴成绩单（教务系统复制即可，智能解析，含夏季学期并入春季）、上传 docx 培养方案、拖入开课 JSON。
- **培养方案对照**：一键把已修的课对照进各培养方案模块，算每个模块达标情况、总学分、GPA。
- **课程规划**：课程速查搜索拖拽、未来学期自动排课、上课时间冲突检测、叠课容忍。
- **毕业口径**：总学分要求取 `max(167, 培养方案要求)`（全校最低 167）；辅修方案则用自身要求。
- 数据默认按学制为"大三"推算，可在设置里改入学年份与当前学期；无夏季学期。

## 使用

```bash
# 直接打开（无需任何安装）
index.html
```

或一行起本地静态服务：

```bash
# python
python -m http.server 8000
# node
npx serve .
```

## 数据来源

公开课程与培养方案来自 `catalog.ustc.edu.cn`（2026-08 抓取），内置在 `js/data-ustc.js`。抓取脚本见 [`crawler/`](crawler/README.md)；刷新数据时按需运行，不需重跑即可使用。

## 目录

```
index.html        入口（双击即用）
css/              样式
js/               应用逻辑（全部随库内置数据）
crawler/          数据抓取脚本与说明
```

## 浏览器兼容

Chrome / Edge / Firefox 现代版本。数据存于浏览器 localStorage，换电脑可用「导出备份 JSON」迁移。
